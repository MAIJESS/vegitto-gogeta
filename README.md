# Vegitto+Gogeta

Un tema visual inspirado en las dos fusiones más poderosas de la franquicia Dragon Ball (**Vegitto y Gogeta**), diseñado específicamente para adaptarse a la interfaz de **Kino TV**.

---

## 🎨 Características
- **Paleta Dual Neón:** Combina el azul energía de los pendientes Potara / Vegitto SSB con el naranja brillante del chaleco Metamor / Gogeta.
- **Optimizización de Interfaz:** Resaltados visuales adaptados para control remoto en Android TV y navegación fluida en dispositivos móviles.
- **Ligero y seguro:** No requiere permisos de red adicionales.

## 🚀 Instalación en Kino TV

1. Abre **Kino TV** en tu dispositivo.
2. Navega hasta **Ajustes > Plugins**.
3. Selecciona **Agregar plugin** e introduce la URL directa de tu repositorio de GitHub (o carga los archivos locales si estás en modo desarrollador).
4. Activa el tema **Vegitto vs Gogeta** desde el menú de temas.
